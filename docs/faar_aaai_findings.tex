\section{Executive summary}

The repository is on branch \texttt{faar-aaai-experiments}. It contains two related but different evidence layers:

\begin{enumerate}
  \item The prototype layer contains a reproducible, offline, 40-example mock evaluation and the implemented FAAR controller.
  \item The AAAI execution layer contains the locked protocol, model and dataset provenance, asset preparation, smoke testing, and commands for the planned B0 to B4 baselines.
\end{enumerate}

The central result of this audit is:

\begin{center}
\fbox{\parbox{0.92\linewidth}{\centering
The planned AAAI baselines B0, B1, B2, B3, and B4 have produced \textbf{zero of five paper-eligible result files}. The only B0 file is explicitly a one-document smoke test and is marked \texttt{paper\_result=false}.
}}
\end{center}

The prototype slice does contain numbers. On the current 40-example offline mock profile run, every compared profile has EM $=0.1250$ and F1 $=0.2036$. FAAR has not shown a quality advantage over \texttt{naive\_rag} on this slice: the recorded deltas are zero. The same artifacts support selective routing and diagnosis-policy consistency, but they do not support a broader answer-quality improvement claim.

The remaining work is therefore experimental execution, not another paper rewrite: complete the GPU-backed assets, finish ArXivQA page confirmation and OCR, obtain MP-DocVQA, run B0 to B4 in order with B2 included, and only then populate paper tables.

\section{What remains}

The next execution sequence is:

\begin{enumerate}
  \item Choose or provision a GPU workflow for complete OHR val/test page rendering and GOT-OCR. The observed MPS smoke rate is not a practical full-dataset plan.
  \item Finish the 500 ArXivQA QA-to-paper/page confirmations. Keep every mapping human-confirmed and retain complete-paper retrieval corpora.
  \item Run pinned GOT-OCR for the 8,955 ArXivQA pages and emit per-page provenance before registering the dataset.
  \item Download the authenticated MP-DocVQA validation set from the RRC Task 4 portal and record checksums.
  \item Run the planned baselines in order: B0, B1, B2, B3, and B4. Save each result before starting the next. B2 must be included.
  \item Tune the gate on validation data only after a real B0 result exists, then lock the threshold.
  \item Run the human annotation study, FAAR test runs, ablations, confidence intervals, failure-type analysis, and paper tables.
\end{enumerate}

Until Step 5 is complete, the correct supervisor statement is: ``The FAAR implementation and experiment controls are substantially prepared, but the paper-eligible B0 to B4 baseline results are still pending because full OCR assets, ArXivQA confirmation/OCR, MP-DocVQA access, and paid baseline execution are not complete.''
